A tiny program that writes one line about a small good thing that happened today: at 7 a.m. the stray cat I call Chai, who steals my samosas, left a dead leaf on my doorstep — rent, apparently — so I paid her in biscuits, and she purred like a kettle and stayed for breakfast.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes a single line to `out/entry.txt`.
